# Русская эмиграция первой волны

Учебный сайт с презентацией по модулю «История России».

Автор: Бортулев Александр Сергеевич, ИТМО.  
Преподаватель: Вычеров Дмитрий Александрович.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main** и папку **/ (root)**, затем нажмите **Save**.

Главная страница — `index.html` в корне репозитория. Сборка и установка зависимостей не требуются.

## Файлы

- `index.html` — сайт со встроенной презентацией.
- `slides.html` — отдельный просмотр 12 слайдов.
- `presentation.html` — автономная презентация со встроенными изображениями для просмотра без интернета.
- `assets/` — обложка и архивные фотографии.

Ссылки на исторические источники приведены на сайте и в презентации. Обложка — созданная с помощью ИИ иллюстрация вымышленной встречи.
